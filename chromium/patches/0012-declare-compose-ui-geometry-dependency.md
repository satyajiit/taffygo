# 0012 — Declare androidx.compose.ui:ui-geometry as a Chromium-consumable dependency

**Status:** `[Current]` — applied 2026-08-17 during the on-device product
bring-up; this specification was written after the patch, against the
specification-first rule, and exists to close that gap rather than hide it
**Needed by:** WP-M1-02 — composable drawing code in the status island
references `Size` and `Offset` from `ui-geometry` directly, and the bytecode
dependency validator requires a direct edge for every directly referenced
class
**Estimated size:** ~10 modified upstream lines, 2 files

## Upstream files and symbols

| | |
|---|---|
| File | `//third_party/androidx/build.gradle.template` |
| Symbol | the `dependencies` block's `compileLatest` list |
| File | `//third_party/androidx/BUILD.gn` |
| Symbol | `androidx_java_group("androidx_compose_ui_ui_geometry_java")` |

## The change

Two halves that are really one: the artifact was reachable only transitively,
absent from `build.gradle.template`, so the generator emitted its
`java_group` with an androidx-only visibility constraint. The template entry
is the real change — the next androidx roll regenerates the group without the
constraint — and the `BUILD.gn` edit is that regeneration applied by hand,
exactly as the generated file's own comment instructs.

```text
build.gradle.template:  + compileLatest 'androidx.compose.ui:ui-geometry:+'
BUILD.gn:               - the visibility constraint on the generated group
```

## Why the overlay cannot host it

Both files are Chromium-owned, and the constraint being removed is *in* the
generated upstream file. There is no downstream mechanism to widen the
visibility of an upstream target from outside it.

## Rebase risk

**Low, self-retiring at every androidx roll.** The `BUILD.gn` half is
regenerated by upstream tooling; after any roll that ingests the template
entry, the hand-applied half either merges cleanly or has already happened.
If the roll drops the template entry, the build fails loudly at the island's
first `Size`/`Offset` reference.

**Retirement:** upstream the template entry (a one-line CL of a kind upstream
accepts routinely). Until then the patch re-applies mechanically.

## Regenerating the patch

```bash
./tools/chromium/sync
# edit the two files in the checkout; commit with the Taffy-Patch trailer
./tools/chromium/export-patches
./tools/check fast
```
