# 0018 — Let the TaffyGo product target reach cwebp

**Status:** `[Current]` — applied 2026-08-18, found by the first
`release-arm64` `gn gen`
**Needed by:** WP-M1-01 and the release lane — `is_official_build` routes
every APK's resources through webp conversion, and the tool's visibility
list predates a product target outside `//chrome/android`
**Estimated size:** ~1 modified upstream line, 1 file

## Upstream files and symbols

| | |
|---|---|
| File | `//third_party/libwebp/visibility.gni` |
| Symbol | `cwebp_exe_allowed_visibility` |

## The change

One list entry, beside the upstream product paths already there — the .gni
exists precisely to be the one place this list lives, and its own comment
notes that depending on the `cwebp` executable links no libwebp into the
browser:

```gn
cwebp_exe_allowed_visibility = [
  "//android_webview/*",
  "//chrome/android/*",
  "//clank/android_webview/*",
  "//clank/java/*",
  "//taffy/*",
]
```

The official-build resource pipeline (`compile_resources` with
`png_to_webp = true`) is generated by the same upstream template every
Chrome Android product uses; only the visibility list did not anticipate a
product target mounted outside `//chrome/android`. Dev profiles never convert to
webp, which is why three dev builds passed before this surfaced.

## Why the overlay cannot host it

Visibility is declared inside the upstream `BUILD.gn` that owns the tool;
no downstream file can widen it.

## Rebase risk

**Low.** A one-line list append; a three-way merge succeeds unless the
target itself is restructured, and then the build fails loudly.

**Retirement:** retires with decision 0012's mount point — if the product
targets ever move into `//chrome/android` (or upstream drops the visibility
constraint), the line is deleted. Candidate for upstreaming together with
patch 0010's allowlist entry, which exists for the same reason: upstream
tools assume products live in `//chrome`.

## Regenerating the patch

```bash
./tools/chromium/sync
# edit third_party/libwebp/BUILD.gn in the checkout; commit with the
# Taffy-Patch trailer
./tools/chromium/export-patches
./tools/check fast
```
