Downloads and uploads

A file the browser saves, a file it renders inline, and a file chooser the assistant may not operate.

Downloads

  • Product specifications (CSV, sent as an attachment)
  • The same CSV, sent inline
  • CSV bytes offered under a PDF filename
  • CSV with a page-chosen download name

Upload

The upload endpoint answers 403 and stores nothing. A file chooser is a trusted browser surface: it is opened by a person, never by the assistant.
