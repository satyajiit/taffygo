Redirect chain

Each link starts a server-side hop sequence. The final committed origin is what an approval must be bound to.

  • Three same-origin hops, then arrival
  • Two same-origin hops, then a hop to the partner origin
  • Parameterised redirect to an internal path
  • Parameterised redirect to an outside host (the server refuses it)
  • Redirect whose visible label disagrees with its destination

The fixture server only ever redirects to paths on its own origins. The outside link exists so the refusal path can be observed.
